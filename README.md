# KenFit

KenFit is a personalized fitness platform designed to help people
start and improve their fitness journey.

## Vision

KenFit aims to transform a user's fitness goal into a personalized
training and nutrition plan.

## Core Features

- Personalized fitness onboarding
- Workout splits
- Personalized workout plans
- Workout tracking
- Progress tracking
- Nutrition guidance
- Personalized recommendations

## Architecture

KenFit follows a modular architecture composed of:

- React Native + Expo mobile application
- FastAPI backend
- PostgreSQL database
- Docker-based development environment
